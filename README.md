# cohen-r.github.io

Personal site for Rachel Cohen, built with Jekyll on GitHub Pages.

## Where to edit things

| To change…                         | Edit                      |
|------------------------------------|---------------------------|
| Name, email, Scholar, ORCID, CV    | `_config.yml`             |
| Intro, research, and about text    | `index.md`                |
| Publications                       | `_data/publications.yml`  |
| Teaching notebooks                 | `_data/notebooks.yml`     |
| Courses taught                     | `_data/courses.yml`       |
| Teaching intro text                | `teaching.md`             |
| Colors and fonts                   | `assets/css/style.css`    |

Put your CV and any paper PDFs in `files/`, then link them as `/files/name.pdf`.
